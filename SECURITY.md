# Security

The owner service runs on loopback. Keep archive directories, owner login links, attachment objects, and backups private. Use the reviewed static site bundle for publication. Configure online hosting only when you intend to publish online.

If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise request a private contact channel from the repository maintainers before sharing details. Include affected versions, a concise impact description and a reproduction using synthetic data. Keep archive contents, credentials, account identifiers, and machine paths out of the report.
