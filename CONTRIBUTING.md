# Contributing

Run the standard test suite from the checkout root. Use a new data directory and create fictional records and attachments for reproductions. Include the behavior you expected, the actual result, and the runtime versions. Remove identifying data from diagnostics and screenshots before sharing them.

Keep private archive data separate from public release assets. Changes to migrations should preserve stable IDs, relationships, and existing visibility choices. Changes to publication should retain explicit selection, preview, and confirmation. Add regression coverage when existing tests do not cover the changed behavior.

See [Security](SECURITY.md) for handling security reports.
